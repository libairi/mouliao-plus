# 方法索引

按当前问题选择有用的方法。领域只是例子，同一方法可以交叉使用；简单问题无需加载全部方法。

| 方法 | 何时有用 | 场景举例 |
|---|---|---|
| [M01 先调查，再下判断](methods/investigate.md) | 描述笼统、争议很大，或建议依赖未经核实的事实。 | 人生选择、商业判断、内容经营、工作关系 |
| [M02 重新检查问题和目标](methods/reframe.md) | 用户把某个方案当成唯一出路，或解决了表面问题仍没有改善。 | 人生选择、商业判断、内容创作、工作规划 |
| [M03 找出当前最影响结果的约束](methods/key-tension.md) | 问题很多、资源有限，需要判断先解决什么。 | 人生选择、商业判断、内容经营、团队工作 |
| [M04 让行动检验判断](methods/experiment.md) | 争论无法靠现有资料解决，但存在成本可承受的试验。 | 人生选择、商业验证、内容试验、工作方法 |
| [M05 把个人取舍和时间尺度讲清楚](methods/tradeoffs.md) | 不同选项都合理，却各自牺牲不同的生活、时间或资源。 | 人生选择、职业选择、商业判断、内容规划 |
| [M06 检查长期积累是否正在发生](methods/long-term.md) | 用户在频繁换方向与长期坚持之间犹豫。 | 人生选择、能力学习、商业合作、内容品牌 |
| [M07 把行动缩到可以开始](methods/start-small.md) | 用户知道大致目标，却迟迟不能开始或总在准备。 | 个人行动、内容生产、项目推进、工作安排 |
| [M08 检查口头目标和实际激励](methods/incentives.md) | 行为与承诺、制度或公开目标不一致，需要理解相关方。 | 工作关系、团队管理、商业合作、内容协作 |
| [M09 从对方的具体情境看价值](methods/value-context.md) | 自认为有用的产品、内容或提案没有得到期待回应。 | 商业判断、内容表达、工作提案、职业能力 |
| [M10 检查做法与资源条件是否匹配](methods/resource-fit.md) | 模仿成功案例却无法执行，或现有组织很难支持新尝试。 | 商业判断、工作安排、内容项目、个人规划 |
