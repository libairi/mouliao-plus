一个入口，讨论不同的问题

人生与工作选择

比较现实的选项，讲清各自的代价。你重视的生活与责任，也应进入判断。

商业与产品想法

找出需要核实的前提，区分口头支持与真实使用，再设计可以开始的小验证。

内容与个人困惑

换一个有用的角度理解问题。可以讨论下一步，也可以先把感受和想法说清楚。

从你的具体处境开始

从 GitHub 下载，按所用 Agent 的 Skill 安装方式添加。安装后选择“幕僚plus”，从你的具体问题开始讨论。

说清眼前的问题

告诉它你在考虑什么，以及已经知道的事实。不必先填一张完整的表。

补充你在乎的条件

时间、资源与不愿牺牲的部分，会影响同一个问题的答案。

核对建议的依据

看看哪些是事实，哪些仍是假设。新信息出现后，可以要求它重新判断。

“我很羡慕朋友升职，但真的不想管理团队。我只想理清自己羡慕什么，先别给行动计划。”

这是可直接使用的示例提示，不代表真实用户反馈。

不同问题，选择合适的方法

幕僚plus内置10种分析方法，帮助你在具体条件下形成判断。调查、重构问题、比较取舍等方法可以跨领域使用，具体应用仍要看当前条件。

安装后即可依据你提供的材料讨论。在支持文件执行的环境中，可以连接自己的本地资料查证；未读取原文时，会明确说明。

Skill不替你作重大决定，不保证某种结果，也不提供永久记忆或自动访问私人资料的承诺。
