使用帮助

这里提供幕僚plus的自助说明，当前不公开个人联系方式，也不提供人工支持通道。

怎样开始

在支持的宿主中选择幕僚plus，描述你面临的问题、已经知道的事实，以及你希望得到的帮助。可以明确要求只讨论想法、比较选项，或形成下一步。

无法找到Skill

当前通过 GitHub 和压缩包分享。下载后，让你的 Agent 按仓库 README 安装 skills/mouliao-plus 文件夹，再选择“幕僚plus”。账号和安装问题也可以查阅OpenAI帮助中心。

为什么不能读取开发者的书

Skill没有附带开发者的书籍全文。基本讨论使用方法摘要；原文查证需要用户提供可访问的材料，并由宿主提供相应文件执行能力。

为什么不能给出准确页码

没有核对具体版本时，不应给出确切页码。可以提供所用书籍或相关页面，再要求按书名、章节和短语核对。

怎么纠正不合适的回答

补充它遗漏的事实，指出你不同意的前提，并说明希望它重新比较的选项。内容问题也可以使用宿主提供的反馈功能。

怎么停止使用和清理资料

可以在宿主停用或卸载Skill。自行建立的本地索引由用户管理，需要时自行删除。宿主中的对话记录按宿主提供的方式管理。
